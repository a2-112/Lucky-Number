# 🔮 Lucky Number Quote Teller

> *Your name is your number. Let the number reveal your quote.*

A small JavaScript project that calculates a unique lucky number from a first and last name, then uses that number to fetch a matching quote from an API.

## ✨ Features

* Custom lucky-number algorithm
* API-powered quotes and authors
* Random quote fallback when a matching quote isn't found
* Error handling for failed API requests
* Input validation
* Loading and reveal animations
* Responsive design

## 🧠 How It Works

1. Enter a first and last name.
2. The app counts vowels and consonants.
3. It calculates a lucky number from the name.
4. The number is used as a quote ID.
5. If the quote doesn't exist, a random quote is fetched.
6. If the API connection fails, an error message is shown.
